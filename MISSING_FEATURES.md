# Missing Features

This file tracks larger Pathfinder 1e systems that still need design and implementation.

- Class archetypes, including class feature replacement, archetype editing, and incompatible archetypes.
- Correct learned skill calculations and class skill integration.
- Feat scraping.
- Favored class bonuses.
- Racial features.
- Available skill ranks per level according to class.
- Language scraping.
- Variant multiclassing (VMC).
- Attribute bonuses every 4 levels.
- Trait scraping.
- Correct animal companion, familiar, and similar companion handling.
- Multiple maps per campaign.
- Fog of war for maps.
- Figure out the most useful permissions for group resources handling and stat visibility.
